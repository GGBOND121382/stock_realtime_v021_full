# AS1455 Android 高速人工下单助手

这是一个 **人工下单辅助器**，不是自动交易执行器。

它只做四件事：

1. 从本地 CSV 读取并预校验订单；
2. 用 AutoJs6 悬浮窗持续显示当前订单；
3. 由用户点击按钮把代码、数量、参考价写入系统剪贴板；
4. 由用户在同花顺完成实际录入、核对和委托后，点击“已下单 →”推进队列。

**它不会读取、定位、点击、填写或确认同花顺的任何控件。**

## 为什么采用悬浮助手

目标是减少在 CSV / WPS / 同花顺之间反复切换造成的时间和错行风险，同时保留最终交易动作的人工控制。

悬浮窗始终展示：

- 买入/卖出方向；
- 6 位股票代码及市场后缀；
- 可选股票名称；
- 数量，并明确单位为“股”；
- CSV 参考价；
- 当前进度、跳过笔数、120 秒节奏偏差。

## 文件

- `manual_fast_assistant.js`：AutoJs6 悬浮助手入口。
- `lib/manual_order_queue.js`：CSV 解析、订单校验、队列与状态机；不依赖 Android，可单元测试。
- `config.example.json`：配置模板。
- `tests/manual_order_queue_test.js`：Node.js 单元测试。

## CSV 格式

最小字段：

```csv
symbol,side,shares,raw_exec_price
000032.SZ,buy,300,16.06
601615.SH,buy,500,9.80
```

支持以下别名：

- 代码：`symbol` / `code` / `证券代码` / `股票代码`
- 方向：`side` / `方向` / `买卖`
- 数量：`shares` / `qty` / `quantity` / `数量` / `股数`
- 价格：`raw_exec_price` / `submit_price` / `price` / `价格` / `委托价`
- 名称（可选）：`name` / `stock_name` / `security_name` / `证券名称` / `股票名称`

默认校验：

- 代码必须是 6 位数字，可带 `.SZ` / `.SH`；
- BUY 数量必须是 100 股的整数倍；
- SELL 允许正整数数量；
- 同一批次默认禁止重复的 `方向 + 代码`；
- 参考价若存在必须为正数。

## 使用

1. 把 `android_manual_order_assistant/` 整个目录放到 AutoJs6 工作目录。
2. 将 `config.example.json` 复制为 `config.json`。
3. 将当日订单 CSV 放到同一目录，并在 `config.json` 中填写文件名。
4. 给 AutoJs6 授予悬浮窗权限。
5. **在 14:55 前**登录同花顺并完成预检查，然后运行 `manual_fast_assistant.js`。
6. 悬浮窗可拖动到不遮挡交易输入框的位置。
7. 每笔交易由用户在同花顺实际录入并核对；委托完成后点击悬浮窗“已下单 →”。
8. 无法立即处理的订单点“跳过 →”。正常队列完成后，助手自动进入“异常补单”阶段。

## 120 秒模式

默认 `target_seconds=120`。顶部会显示：

```text
已完成 / 总笔数    跳过数    正常队列/异常补单
已用时间 / 目标时间    节奏差
```

“节奏 +3”表示当前完成笔数比 120 秒均匀节奏应达到的笔数多 3 笔；负数表示落后。

这里的 120 秒只是操作节奏指标，不代表任何交易能够或应该在该时间内成交。

## 防错设计

- **不自动推进**：复制代码/数量/价格不会把订单标记为完成；只有人工点击“已下单 →”才会推进。
- **跳过不阻塞**：异常订单不会卡住后面的正常订单。
- **自动进入异常队列**：正常订单处理完后，再集中补处理跳过项。
- **计划指纹**：CSV 内容变化后使用新的状态文件，避免旧进度污染新计划。
- **防双击**：完成/跳过/复制按钮带短时间防抖。
- **可回退**：误点完成或跳过后可“回退上一笔”。
- **持久化**：脚本退出或手机切换后可继续当前计划。
- **不依赖同花顺 resource-id / 坐标**：同花顺更新 UI 不会导致助手去点击错误控件。

## 同花顺操作前检查

建议在交易窗口开始前完成，而不是边下单边处理：

1. 确认登录的是正确券商和账户；
2. 确认当前使用的委托类型、价格输入方式符合当日执行规则；
3. 固定横屏/竖屏，避免输入过程中页面重排；
4. 延长屏幕待机时间，避免中途锁屏；
5. 确认网络连接稳定、交易模块已登录；
6. 将悬浮窗拖到不覆盖同花顺股票代码、价格、数量、买卖按钮和确认信息的位置；
7. 每笔最终确认时，用同花顺页面上的证券名称、方向、数量、价格与悬浮窗做一次视觉核对；
8. 遇到风险提示、不可交易、价格/数量不合法等异常，不要反复尝试，先“跳过”并继续正常队列。

## 关于参考价

`raw_exec_price` 在助手里明确显示为 **CSV参考价**。助手不会判断该价格在真实下单时是否仍有效，也不会替用户选择限价、市价或其他委托类型。

如果你的真实执行流程不需要手工录入价格，可以设置：

```json
"show_price": false
```

这样可以减少视觉信息和误触。

## 测试

队列逻辑可在 PC 上执行：

```bash
node tests/manual_order_queue_test.js
```

该测试不连接同花顺，也不执行任何交易操作。
