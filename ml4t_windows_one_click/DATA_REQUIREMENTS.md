# ML4T Local Data Requirements

This directory tracks the code needed by the one-click ML4T reproduction scripts,
but not the large local data or generated experiment outputs.

Copy or generate these files locally before running the scripts:

| Required file | Put it at | Used by | How to obtain |
| --- | --- | --- | --- |
| `wiki_prices.csv` | `ml4t_windows_one_click/machine-learning-for-trading/data/wiki_prices.csv` | Builds `assets.h5` when missing | Download Nasdaq Data Link WIKI/PRICES export, unzip, rename to `wiki_prices.csv` |
| `wiki_stocks.csv` | `ml4t_windows_one_click/machine-learning-for-trading/data/wiki_stocks.csv` | Builds `assets.h5` when missing | Copy from the official ML4T repo `data/` directory |
| `us_equities_meta_data.csv` | `ml4t_windows_one_click/machine-learning-for-trading/data/us_equities_meta_data.csv` | Builds `assets.h5` when missing | Copy from the official ML4T repo `data/` directory |
| `assets.h5` | `ml4t_windows_one_click/machine-learning-for-trading/data/assets.h5` | Chapter 7, Chapter 12, Chapter 17 data preparation | Generated from the three files above by the one-click scripts |
| `data.h5` | `ml4t_windows_one_click/machine-learning-for-trading/07_linear_models/data.h5` | Chapter 7 RMSE runner fast path | Generated by Chapter 7 notebooks |
| `data.h5` | `ml4t_windows_one_click/machine-learning-for-trading/12_gradient_boosting_machines/data.h5` | Chapter 17 NN training input | Generated by Chapter 12 `04_preparing_the_model_data.ipynb` |
| `scores.h5` | `ml4t_windows_one_click/machine-learning-for-trading/17_deep_learning/results/scores.h5` | Chapter 17 NN training result cache | Generated by Chapter 17 `04_optimizing_a_NN_architecture_for_trading.ipynb` |
| `test_preds.h5` | `ml4t_windows_one_click/machine-learning-for-trading/17_deep_learning/results/test_preds.h5` | Chapter 17 Zipline backtest input | Generated by Chapter 17 `04_optimizing_a_NN_architecture_for_trading.ipynb` |

Generated reports under `ml4t_windows_one_click/out/` are also ignored by Git.
