# legacy experiments

root script list.

These scripts are useful as historical references, but the current main workflow
is documented in `../../README.md` and runs through scripts such as
`model_training/optimize_nextday_vwap_model.py`,
`model_training/search_walk_forward_model_complexity.py` and
`pipelines/run_nextday_pipeline.py`.
