# Historical Score → Portfolio Backtest, no mandatory history_close.csv

这版替换：

```text
portfolio_decision/backtest_historical_score_portfolio.py
scripts/backtest_historical_score_portfolio.sh
```

核心变化：

```text
1. 不再默认要求 history_close.csv。
2. 主输入是 saved_models/*/*/metadata.json 指向的 historical samples。
3. 如果 metadata.samples 不存在，脚本直接报错并打印恢复命令：
   python3 pipelines/run_premarket_history_update.py ...
4. 如果没有显式 HISTORY，脚本只在内存中从 samples 的 close 列构造估值用历史价格表；
   不再额外生成 autogenerated_history_close.csv。
```

## 应用

```bash
cd /root/stock_realtime_v021_full
unzip -o /path/to/historical_backtest_no_history_table_patch.zip -d .
```

## 运行

```bash
START_DATE=2026-05-01 END_DATE=2026-05-15 INITIAL_CASH=200000 \
PYTHON=python3 bash scripts/backtest_historical_score_portfolio.sh
```

只生成历史每日打分，不跑 portfolio：

```bash
SCORE_ONLY=1 START_DATE=2026-05-01 END_DATE=2026-05-15 \
PYTHON=python3 bash scripts/backtest_historical_score_portfolio.sh
```

如果你有独立历史收盘价文件，才显式传：

```bash
HISTORY=/path/to/close_history.csv PYTHON=python3 \
bash scripts/backtest_historical_score_portfolio.sh
```

## metadata.samples 缺失时

脚本会列出缺失的 artifact 和 samples 路径，并打印类似命令：

```bash
python3 pipelines/run_premarket_history_update.py \
  --models-dir saved_models \
  --saved-data-dir saved_data \
  --context-config configs/realtime_context_sources.toml \
  --symbols 603308.SH,600312.SH \
  --end-date today \
  --keep-going
```

恢复完成后再跑回测。
